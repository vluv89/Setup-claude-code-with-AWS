# Contributing

Thanks for helping improve this guide.

## How to contribute

1. Fork the repository.
2. Create a branch for your change.
3. Keep examples generic; never include real account IDs, access keys, secret keys, tokens, emails or private infrastructure details.
4. Verify PowerShell examples and links where possible.
5. Submit a pull request explaining what changed and how it was checked.

## Reporting issues

Include the operating system, PowerShell version, AWS CLI version, Claude Code version, Region and a redacted error message. Do not include credentials, account identifiers or sensitive logs.

## Scope

This project focuses on beginner-friendly Windows/PowerShell setup for Claude Code with Amazon Bedrock. Prefer official AWS and Anthropic documentation for version-sensitive instructions.
